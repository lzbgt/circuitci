# Nexperia PRTR5V0U2X USB ESD Observation

This direct-open GUI example validates a reduced generated-SPICE face for the
source-backed Nexperia PRTR5V0U2X rail-to-rail USB ESD array.

The observation checks normal USB line and VBUS voltages against the 5.5 V
standoff limit while loading the data lines with the datasheet capacitance
metadata. It is a preliminary normal-operation design check, not an IEC ESD
pulse clamp, USB eye, differential-impedance, leakage-over-temperature, or PCB
layout sign-off model.

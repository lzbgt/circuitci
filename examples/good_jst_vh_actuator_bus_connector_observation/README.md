# JST VH Actuator Bus Connector Observation

This generated-SPICE fixture exercises the source-backed
`vendor.jst.vh_8pin_actuator_bus_header` connector face. The reduced model
uses the JST VH datasheet post-test 20 mOhm maximum contact resistance per
mated contact to observe 12 V actuator-bus voltage drop and low-current control
line pass-through.

It is a connector contact-drop smoke test. It is not a cable harness,
temperature-rise, current-sharing, CAN signal-integrity, vibration, retention,
or crimp-quality sign-off model.

# JST XH Servo Connector Observation

This generated-SPICE fixture exercises the source-backed
`vendor.jst.xh_3pin_servo_header` connector face. The reduced model uses the
JST XH datasheet post-environmental-test 20 mOhm maximum contact resistance per
mated contact to observe load-side VCC/GND/SIG voltage drop.

It is a connector contact-drop smoke test. It is not a cable, crimp,
temperature-rise, retention, vibration, or signal-integrity sign-off model.

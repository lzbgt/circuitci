# Microchip ATECC608A I2C Secure Element Observation

This direct-open GUI example exercises the source-backed ATECC608A I2C secure
element observation model. It verifies the board-level 3.3 V supply and idle
I2C pull-ups only; cryptographic commands, provisioning, secure boot, RNG,
wake/sleep timing, and bus timing sign-off are intentionally out of scope.

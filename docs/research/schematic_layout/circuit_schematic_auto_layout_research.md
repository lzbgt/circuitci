## Findings

The relevant common algorithm family is layered graph drawing, also called the
Sugiyama framework. ELK, Graphviz `dot`, and OGDF all expose this family for
directed diagrams. ELK is the closest conceptual match for schematic and
Simulink-like diagrams because it models explicit ports, port sides, and
orthogonal edge routing. Graphviz `dot` provides mature layered ranking and
crossing reduction, while OGDF documents both layered and orthogonal graph
drawing algorithms.

For this project, adding ELK or OGDF as a runtime dependency would be excessive:
the GUI already stores Board IR schematic positions, symbol style metadata,
KiCad pin anchors, and display-only wire routes. A small in-process pass can use
the same core ideas without adding a JavaScript, Java, or C++ layout engine:

- Build a circuit-flow ranking from source outputs through non-power,
  non-ground signal nets.
- Use explicit KiCad symbol pin anchors as ports when available.
- Place power nets on the top rail and ground nets on the bottom rail.
- Place sources on the left, series components by rank on the signal path, and
  one-rail shunt parts in vertical lanes between signal and rail.
- Apply bounded barycentric ordering within each rank to reduce crossings
  between sibling branches before assigning schematic lanes.
- Persist orthogonal wire waypoints from the ranked symbol port positions.

This is not a full global crossing-minimization implementation, but it now has
the core layered-graph primitives needed for textbook circuits: ranked layers,
local barycentric crossing reduction, ports, rails, orthogonal routes, and
persisted display metadata. Those are the same primitives needed if the project
later embeds a full ELK-like pipeline or imports a schematic layout generated by
another open-source tool.

## Implementation Direction

The implemented direction is a dependency-free circuit-flow ranker inside the
existing Sketch layout module:

1. Seed rank `0` with source components.
2. Seed rank `1` with source-connected signal nets.
3. Propagate ranks through connected components and onward to other signal nets.
4. Run a small fixed-iteration barycentric sweep so components and nets sharing
   a rank are ordered by the average lane of their neighbors, following the
   same crossing-reduction idea used by layered graph drawing systems.
5. Use the rank map to place series parts and signal nets left-to-right.
6. Keep power/ground nets as rails and place shunts vertically between rails.
7. Continue using KiCad/imported symbol pin geometry for route endpoints.

The direct GUI examples should bind explicit KiCad symbols and orientation
metadata so the ranked layout opens with canonical library glyphs, not inferred
fallback symbols.
